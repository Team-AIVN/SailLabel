| 역할 | 설명 | 주요 권한 | 접근 허용 | 접근 금지 |
| --- | --- | --- | --- | --- |
| **전체 시스템 관리자 (Super Admin)** | 플랫폼의 모든 기능을 제어하고 관리하는 최상위 사용자입니다. | - 사용자(관리자, 작업자) 계정 생성, 수정, 삭제- 전체 프로젝트 생성, 조회, 수정, 삭제- 시스템 전반의 설정 및 유지보수 | 모두 | 없음 |
| 워크스페이스 관리자 (Workspace Manager) | 워크스페이스의 모든 기능을 제어하는 사용자입니다. | - 워크스페이스 생성, 수정, 삭제- 워크스페이스 내 프로젝트 생성, 수정, 삭제- 프로젝트에 프로젝트 관리자 설정- 데이터셋 업로드 설정 | 내 소속 워크스페이스 모든 기능 | 내가 소속되지 않은 워크스페이스 |
| **프로젝트 관리자 (Project Manager)** | 특정 프로젝트를 책임지고 관리하는 사용자입니다. 작업자 할당, 진행 상황 모니터링, 비용 정산 등을 담당합니다. | - 담당 프로젝트 내 작업자 초대 및 역할(라벨러, 검수자) 할당- 데이터셋 업로드 및 라벨링 인터페이스 설정- 검수 설정- 작업자 - 어노테이터/리뷰어 각각 설정- 작업자별 작업 진행도 및 완료량 실시간 모니터링- 작업자별 작업 성과에 따른 **비용 정산 및 리포트 생성**- 최종 결과물 승인 및 피드백 제공 | 내 소속 워크스페이스 (내 소속 프로젝트, 작업집합, 멤버, 보상만 보이고 조회만), 내 소속 프로젝트 모든 기능 | 위의 모든 것, 내가 소속된 워크스페이스의 관리 기능, 내가 소속되지 않은 프로젝트 |
| 작업자: 라벨러 (Labeler) | 실제 데이터 관련 작업을 수행하는 사용자입니다. | [라벨러]- 할당된 라벨링 작업 목록 조회- 라벨링 인터페이스를 통한 데이터 주석 작업 수행- 작업 내용 저장 및 제출 | 내 소속 프로젝트의 라벨링 작업 기능 | 프로젝트 관리자의 모든 접근 금지 항목들, 내 소속 프로젝트의 관리 기능, 검수 작업 기능 |
| 작업자: 검수자 (Reviewer) | 실제 데이터 관련 작업의 검수를 수행하는 사용자입니다. | [검수자]- 검수 대상 작업물 목록 조회- 라벨링 결과물 검수 및 수정, 피드백 작성- **자신의 검수 기록(수정/승인/반려 내역) 추적** | 내 소속 프로젝트의 검수 작업 기능 | 프로젝트 관리자의 모든 접근 금지 항목들, 내 소속 프로젝트의 관리 기능, 검수 작업 기능 |
| 프로젝트 멤버 / 작업자 (작업 미할당) | 프로젝트에는 할당되었으나 실제 작업을 수행할 수 없는 사용자입니다. 데이터를 보는 것만 가능하고 작업은 할 수 없습니다. | - 프로젝트의 작업집합 조회 | 내 소속 프로젝트 작업 목록 조회 | 위의 모든 것, 프로젝트 작업 목록 조회 외 모든 기능 |
| 워크스페이스 멤버 | 워크스페이스에 할당된 사용자 | - 워크스페이스 소개 조회 | 내 소속 워크스페이스 메인 페이지의 워크스페이스 제목, 설명 조회 | 위의 모든 것 |
